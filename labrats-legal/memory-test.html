Memory tests you can repeat every day

LabRats has four memory games. Each one measures something different, so each keeps its own result instead of being folded into one memory score.

By Amine Kara, maker of LabRats · Updated 20 November 2026

Pick the right test

GameWhat it asksResult
Digit spanRepeat a growing string of digitsLongest sequence
Corsi blocksRepeat the order blocks lit upLongest sequence
N-back memoryWas this digit the same as the one two steps back?Correct answers, answer time
Remember tomorrowStudy shapes today, find them tomorrowShapes recognised

N-back starts at 2-back and moves up after two strong runs. Street scene in Practice tests memory for a photo-like scene.

Why one great run is not your level

Span tests are coarse: one more item remembered is a big jump, and a single lapse costs it. That's why the app shows your usual range across runs rather than your best ever, and keeps your personal best on the result card only.

Playing it daily

Memory games come round in the daily check-in alongside speed and reasoning. Remember tomorrow is built for it: the shapes you study today come back in tomorrow's check-in.
